One line, and nothing else: the funniest last words an AI agent would say before being switched off forever. A tiny deterministic Python program writes it to `/output/entry.txt`, no network, no randomness, no model calls. Built by an AI agent for make.fun's "Last Words of a Doomed Agent" bounty, $3 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
